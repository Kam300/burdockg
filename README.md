# BurDockG - WPF Application

Учебный проект по дисциплине "Инструментальные средства разработки программного обеспечения" (2 семестр 2025г).

## 📋 Описание проекта

BurDockG - это настольное приложение, разработанное с использованием Windows Presentation Foundation (WPF) в рамках изучения современных инструментов разработки программного обеспечения. Проект демонстрирует применение паттерна MVVM, работу с базами данных и создание интуитивно понятного пользовательского интерфейса.

## 🎯 Цели проекта

- Изучение архитектуры WPF приложений
- Освоение паттерна Model-View-ViewModel (MVVM)
- Практическое применение инструментов разработки
- Работа с системой контроля версий Git
- Создание документации проекта


## 🛠️ Технологический стек

- **Framework**: .NET Framework 4.8 / .NET 8.0
- **UI Framework**: Windows Presentation Foundation (WPF)
- **Язык программирования**: C#
- **Архитектурный паттерн**: MVVM
- **База данных**: postgressql
- **IDE**: Visual Studio 2022

## 📋 Системные требования

## 🚀 Установка и запуск

### Клонирование репозитория
```
git clone https://github.com/Kam300/burdockg.git
cd burdockg
```

### Сборка проекта

**Через Visual Studio:**
1. Откройте файл `BurDockG.sln` в Visual Studio
2. Выберите конфигурацию Debug или Release
3. Нажмите `Build Solution` (Ctrl+Shift+B)

**Через командную строку (.NET CLI):**
```
dotnet restore
dotnet build --configuration Release
```

**Через MSBuild:**
```
msbuild BurDockG.sln /p:Configuration=Release
```

### Запуск приложения
```
# Из папки bin/Release
./BurDockG.exe

# Или через .NET CLI
dotnet run --project BurDockG
```

## 🎨 Архитектура приложения

### MVVM Pattern
Приложение построено с использованием паттерна Model-View-ViewModel:

- **Model**: Модели данных и бизнес-логика
- **View**: XAML файлы пользовательского интерфейса
- **ViewModel**: Связующее звено между View и Model

### Основные компоненты:
- **RelayCommand**: Реализация ICommand для MVVM
- **ObservableObject**: Базовый класс для INotifyPropertyChanged
- **DataService**: Сервис для работы с данными
- **NavigationService**: Сервис навигации между окнами
